## 2. Q3 做了什么（时间 / 能耗 / 品质三目标工艺优化）

把"烘房温度"从附件1 给定的观测序列推广为**可设计的三段恒温制度**（切换时点固定 8 h / 24 h，
温度搜索区间 40–70 ℃），做三目标优化。
方法链：136 点 DOE（真模型 n=80）→ 3 阶正交 Legendre-PCE 代理（20 项）→ 8000 候选点上求 Pareto
→ 抽稀 19 点用**真模型 n=160 回代复核** → 熵权 TOPSIS → Ea 稳健性。

| 结论 | 数值 |
|---|---|
| 题目基准（附件1 观测环境） | t60 = **57.1833 h**，SEC = 0.1008 MJ/kg，Q_ret = 0.5218，峰值热流 554 W/m² |
| 时间最优 | 全程 70 ℃ → **32.4667 h（−43.22%）**，Q_ret 降到 0.3405、峰值热流升到 1050 W/m² |
| 能耗/品质最优 | 全程 40 ℃ → 81.0333 h（+41.71%），SEC 0.0574 MJ/kg，Q_ret 0.6006 |
| **TOPSIS 折中（推荐）** | (40.1, 60.2, 45.3) ℃ → 57.9833 h（仅 +1.40%），SEC **0.0848（−15.9%）**，峰值热流 **302 W/m²（−45%）** |
| 主导杠杆 | **末段温度 T3**；前沿上 T1 普遍被压到 40–46 ℃，T3 从 40 拉到 69 ℃ |
| 代理精度 | t60：训练 R² 0.999983、5 折 CV RMSE 0.0496 h；SEC / dose 的 CV RMSE 为 1e-5 / 3.2e-4 |
| Ea 稳健性 | Ea = 30/50/80 kJ/mol 下 TOPSIS 推荐分别为 (41.8, 69.7, 40.0) / (40.1, 60.2, 45.3) / (42.5, 42.4, 48.3) |

## 3. Q4 做了什么（收缩本构内生化 + 孔隙率 + 表皮阻力）

| 结论 | 数值 |
|---|---|
| 基准 | t60 = **50.8333 h**（183000 s），R_end = 1.2000 cm |
| 本构比较 | **径向二次（过初值）最优：RMS 68 μm、R² 0.9975**；径向线性 537 μm；体积线性 996 μm |
| 外推检验 | 前 40% 标定的线性本构预测后段：RMS **0.427 cm**，末端 R 预测 0.708 cm vs 真值 1.200 cm（低估 41%）→ **线性收缩本构不可外推** |
| 内生重算 | 径向二次 **Δt60 = 0.0000 h**；径向线性 −0.1167 h；体积线性 −1.4833 h；前 40% 标定线性 **−23.55 h** |
| 孔隙率（口径A） | 总空隙 0.8035→0.4543；含水体积分数 0.7014→0.0904；**气相孔隙率 0.1022→0.3638** |
| **相容性诊断** | 只用附件2 收缩推算的气相孔隙率最小值 **−0.1403 < 0（物理不可能）**；附件2 的 R/R₀ 与附录4 密度式隐含值最大相差 **0.1292**（@4.5 h）→ **两套经验闭合不能同时严格成立** |
| 表皮阻力 | K_c = 1/2/4 时 t60 分别 +0.87 / +1.87 / **+4.13 h**（最多 +8.13%） |

## 6. 必须随结果一起声明的局限

1. 温度优化区间 **40–70 ℃ 超出附件1 观测范围（28–50.246 ℃）**，附录3 的经验物性式在该区间未标定；
   全部扩展结果属"若允许调温"的情景。
2. 品质降解动力学（k_ref = 0.02 h⁻¹ @60 ℃、Ea = 50 kJ/mol 基准）**取自文献量级、未标定**；
   Q_ret 只作相对排序（已给出 Ea 敏感性）。
3. SEC 只统计**对流供入物料的热量**，模型不含潜热项；另列 SEC + λ（λ = 2.383 MJ/kg）供可比。
4. 改温度制度时空气含湿量仍沿用附件1 的观测序列（未随温度耦合）——显式假设。
5. 固体真密度 ρ_s 未标定；附录4 密度式与附件2 收缩不相容（见 §3）。
6. 表皮阻力情景中 C_crust = 0.5 kg/kg 为假设值，只作方向性分析。
7. 三段恒温、切换时点固定 8 h / 24 h 属设计选择，未对切换时点做优化。
8. 论文整合时须遵守三条硬规矩：**扩展层数字不替换主答案**；新参数标注来源并声明未标定；
   每个扩展点回答题面之外的问题。

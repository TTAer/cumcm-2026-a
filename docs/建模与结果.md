# 药材烘干的有效热质传递模型与计算结果

## 摘要

针对半径2 cm、长度25 cm的圆柱药材，建立一维径向有效热质传递模型。空间采用节点型环形有限体积与表面加密网格，水分非线性通量采用 Kirchhoff 原函数差分，时间采用 Radau 刚性积分。问题1使用附录2参数计算前1800秒的温度和含水率；问题2从原始初态起统一使用附录3，并与问题3共享完整积分过程。以所有空间节点的最大干基含水率低于0.15 kg/kg为达标条件，末次环境观测延拓下，问题3的严格达标秒点为 **205810 s（57.1694 h）**。问题4在均匀径向收缩的材料坐标中采用附录4，严格达标秒点为 **182955 s（50.8208 h）**。

文中给出六张题目要求的结果表及四份完整结果文件，并区分阈值交叉估计、严格达标输出时刻和四位小数显示。三种环境延拓情景的交叉时间覆盖问题3约57.1694—57.4740 h、问题4约50.8207—51.0885 h。该范围只反映选定环境情景的差异，不是全部模型误差上界。模型尚依赖有效环境含水率、忽略显式潜热和一维近似，结果属于这些假设下的计算预测。

**关键词：**圆柱干燥；有效扩散；有限体积；材料坐标；全域阈值

## 二、数据、假设与符号

附件1有241个观测点，覆盖0—14400 s，间隔60 s。区间内分段线性插值，结束后主方案固定为末次观测50.165℃、0.04986 kg/kg。末小时61点均值为49.998934℃、0.049987541 kg/kg，作为另一情景；50℃、0.05为标称平台情景。平台接近末段均值是描述性依据，不证明后续数十小时环境恒定。

附件2半径先由cm换算成m，再进行保形分段三次插值。正式问题4的终点位于附件覆盖时段内，不需要半径远期外推。初始半径R₀=0.02 m、长度L=0.25 m、初温28℃、初始干基含水率2.55 kg/kg。扩散公式中的绝对温度为T+273.15，不能直接代入摄氏温度。

模型假设：

1. 轴对称、一维径向传递，忽略端面传递；不把该近似宣称为已由二维计算验证。
2. 问题4长度不变、各材料点按相同比例径向收缩，内部速度u=rR′/R。
3. 题给经验物性在计算范围内有效；问题2—4沿用h=25 W/(m²·K)、hₘ=8×10⁻⁷ m/s。
4. 环境数值作为含水率方程的有效边界值Cₑ。若其实际定义为干空气基含湿量，则需额外吸附平衡换算，不能仅因单位均为kg/kg就直接相减。
5. 主模型不显式计入蒸发潜热、辐射和完整多相焓输运；不能声称这些影响已经包含在传质系数中。
6. C为干基比值，经验ρ用于热惯性。现有方程属于有效模型，不同时声称经验ρ是严格湿物料密度且模型满足完整干物质连续性。

## 三、模型建立

### 3.1 固定半径模型

在0<r<R内，采用

$$\rho(C)c_p(C)\frac{\partial T}{\partial t}=\frac1r\frac{\partial}{\partial r}\left(rk(C)\frac{\partial T}{\partial r}\right),\qquad
\frac{\partial C}{\partial t}=\frac1r\frac{\partial}{\partial r}\left(rD(T,C)\frac{\partial C}{\partial r}\right).$$

变系数保留在散度内。中心对称边界为Tᵣ(0,t)=Cᵣ(0,t)=0；表面向外法向取正，有

$$-kT_r(R,t)=h[T_s-T_a(t)],\qquad -DC_r(R,t)=h_m[C_s-C_e(t)].$$

初态为T(r,0)=28、C(r,0)=2.55。问题1、问题2分别从初态出发，不能在1800秒将问题1状态拼到附录3过程上。

| 参数 | 问题1：附录2 | 问题2/3：附录3 | 问题4：附录4 |
|---|---|---|---|
| ρ | 820 | 650+128C | 760+90C |
| cₚ | 2600 | 1450+2736C/(C+1) | 1850+2150C/(C+1) |
| k | 0.36 | 0.21+0.38C/(C+1) | 0.12+0.20C/(C+1) |
| D | 7×10⁻⁹exp(−0.89/C) | 2.4×10⁻³exp[−0.45/C−3850/(T+273.15)] | 4.2×10⁻⁴exp[−0.30/C−3850/(T+273.15)] |

### 3.2 问题4材料坐标模型

在所声明的均匀收缩速度场下，物质导数∂ₜ+u∂ᵣ转为固定ξ的时间导数，故

$$\rho c_p\left.\frac{\partial T}{\partial t}\right|_\xi=\frac{1}{R(t)^2\xi}\frac{\partial}{\partial\xi}\left(\xi k\frac{\partial T}{\partial\xi}\right),\qquad
\left.\frac{\partial C}{\partial t}\right|_\xi=\frac{1}{R(t)^2\xi}\frac{\partial}{\partial\xi}\left(\xi D\frac{\partial C}{\partial\xi}\right).$$

表面边界改写为−kTξ/R=h(Tₛ−Tₐ)、−DCξ/R=hₘ(Cₛ−Cₑ)。材料输运与坐标运动在该假设下抵消，不能重复加入收缩对流；C为干基比值，也不能直接增加体积浓度的压缩项。R(t)仅规定边界位置，均匀内部变形仍是独立假设。

### 3.3 数值求解与停止

四问统一采用1280区间表面加密节点ξⱼ=1−(1−j/1280)³ᐟ²。控制体界面取相邻节点中点，体积权重Vⱼ=(ξ²ⱼ₊½−ξ²ⱼ₋½)/2。内部径向通量按界面通量差除以体积权重计算；中心面积为零，避免直接除以r=0。表面已有节点，直接施加膜边界通量，不重复附加半格传质阻力。

令D=A(T)exp(−a/C)，使用原函数

$$F(C)=C e^{-a/C}+a\operatorname{Ei}(-a/C),\qquad F'(C)=e^{-a/C}.$$

内部有效扩散系数取A(T面)[F(C右)−F(C左)]/(C右−C左)，小差值时取连续极限。温度因子在界面近似，不把整段变温通量称为解析精确。热通量采用相邻导热系数调和平均。

时间积分使用Radau，相对容差2×10⁻⁹、绝对容差4×10⁻¹¹、最大步60 s。每秒表格由连续数值解采样产生，区别于简单线性插值分钟表。事件函数g(t)=maxⱼCⱼ(t)−0.15下降过零后，继续实际积分到下一整数秒，确认未舍入最大值严格小于0.15，再导出末行。计算节点上的全域判据是连续空间判据的数值近似，其可信程度由网格检查支持。

## 七、适用边界与可改进方向

**物理闭合。**若ρ代表严格湿物料密度，则干物质密度ρd=ρ/(1+C)，需满足干物质连续性。取J=−ρdD∇C时，应有ρd DC/Dt=∇·(ρdD∇C)。只有附加适当条件，才能简化为当前有效扩散方程。当前离散平均含水率与累积边界流出量之和保持初值，证明的是所用方程收支一致，不能替代真实干物质或水质量守恒。

**潜热。**无显式潜热模型不能凭传质系数存在就宣称已计入蒸发吸热。此前潜热压力情景提示时长可能发生明显变化，且初期温度行为提示需要进一步核对气固平衡；由于缺少本药材相应数据，不能将诊断性潜热情景作为已标定真值。删除“潜热仅影响0.85%”的确定性结论。

**轴向近似。**两端面积/侧面积=R/L，初始8%，收缩到1.2 cm时4.8%；该比值不是预测误差。0.001 cm等于0.01 mm，数值保留位数也不是测量不确定度。需端面条件和二维对照后才能量化轴向影响。

**外推与实测。**缺少内部温湿实测和4小时后的环境观测，无法估计实测预测误差。若进一步获取吸附等温线、内部传感器记录、端面条件和干物质量测量，应优先完善物理闭合并检验参数，而非为追求更多小数位盲目加密。

## 八、结论

在明确的有效模型、last环境延拓和均匀径向收缩假设下，四问的场分布见表1—6及结果工作簿，Q3、Q4严格达标时间分别为205810 s和182955 s。Q2/Q3统一计算来源，Q4采用固定物理位置采样并保留真实表面，终点以未舍入全域最大值证明。模型可用于题给条件下的数值比较，但不应未经实测验证直接作为实际工艺保证。

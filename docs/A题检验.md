## 摘要

工作区内存在 **4 套可检验的求解方案**：同一套物理模型（一维轴对称圆柱径向热质耦合 + Kirchhoff/调和通量 + 中心对称 + 表面 Robin），在**环境延拓口径、空间离散与时间方法**上分叉。

| 方案 | 环境尾值 (t>14400 s) | 0–4 h 插值 | 空间 | 时间 | 结果位置 |
|---|---|---|---|---|---|
| **A-last** | 50.165 ℃ / 0.04986 kg/kg（末次观测） | 分段线性 | 1280 节点 FV，1/2/4 问表面加密 | Radau，rtol 2e-9，最大步 60 s | `A题_终稿/` |
| **A-nominal** | 50 ℃ / 0.05（恒温平台） | 分段线性 | 同上 | 同上 | `求解/` |
| **A-mean** | 49.9989 ℃ / 0.04999（末小时均值） | 分段线性 | 同上 | 同上 | `求解/资料复核改进/mean_*` |
| **B（王翔）** | 50.165 ℃ / 0.04986 | PCHIP（**仅自述，不可核**） | 2560 环，单元中心（自述） | 后向欧拉 + Picard 全耦合（自述） | `王翔/` |

> 注：A 侧三口径的 `env_interp` 在结果文件 `run_config` 中均为 **`linear`**（PCHIP 只用于附件2 半径）；B 侧因**源码全部缺失**，其"PCHIP、2560 环、Picard、后向欧拉"均只能标为**待核验主张**。

**核心结论**

1. **四方案的达标时间一致到"分钟级"，差异几乎全部由环境尾值口径解释**：
   - 全域最大判据下 Q3/Q4：A-last **57.1694 / 50.8208 h**、A-nominal **57.4723 / 51.0871 h**、A-mean **57.4740 / 51.0885 h**、B **57.1833 / 50.8333 h**。
   - 极差仅 Q3 0.3046 h、Q4 0.2677 h（约 16–18 min）。其中把 A 自己的 nominal→last 尾值一换就占去 ≈1091 s / 959 s；而**在同尾值下 A-last 与 B 只差 50 s / 45 s**（线性 vs PCHIP + 网格 + 停止取整的残余）。
   - **场值层面更干净**：把尾值对齐后，A-last 与 B 在**全部公共分钟点、全部公共距离**（Q3 共 3430 个时刻、Q4 共 3049 个）上的 **最大 \|ΔC\| 仅 6.6e-5（Q3）/ 9.6e-5（Q4）kg/kg，均值仅 2.5e-5**（半个末位 5e-5）；**两种尾值口径之间的场差达 1.7e-3 / 3.7e-3，是大 30–60 倍**。→ **两套完全不同的离散/时间算法（节点 FV+Radau vs 环状中心 FV+后向欧拉 Picard）在题目要求的输出精度内不可区分。**
2. **唯一可能颠覆答案的不是算法，而是判据与呈现**：
   - 「全域最大 C<0.15」与「体积平均 C<0.15」相差 **Q3 ≈21.3–21.4 h、Q4 ≈16.0–16.1 h**（约 1/3），必须坚持全域最大；
   - 题面要求的**四位小数在末期无法表达严格达标**：半个末位（5×10⁻⁵）≈171 s（Q3）/97 s（Q4）的过程时间，而达标裕度只有 0.20–0.71 s。**四份交付件末行都显示 0.1500**，"严格 <0.15"只能由未舍入值（summary/npz）证明。
3. **方案 A 侧的交付与自述存在 4 处实质不一致**（result2 覆盖范围、"Q3 均匀网格"、"不收缩"结论、mean 口径未落盘）；**方案 B（王翔）的源码/数组/日志全部不在工作区**——不仅"没提供"，而且**精度指纹（存全精度）与样式指纹（宋体10/freeze A2）证明本目录根本不存在能产出这 4 份工作簿的写入代码**，其生成链完全位于本机不存在的路径 → 算法自述（PCHIP、2560 环、Picard、逐内部步扫描、收敛/残差/账本/哈希链）**一律只能标为"待核验主张"**。B 的 result2 同样只到 3 h，而同工作区 `A题_终稿` 已给全程 205810 行。
4. 四方案在**质量守恒、单调性、非负性、边界包络**上全部通过，说明核心离散实现是可信的；主要风险在**交付口径与论文表述**，不在数值本身。

## 二、检验方法与规则

**规则**：只读（禁止创建/修改/删除）；原始数值优先；不把被检验方案的自述当证据；无法核验即记"存疑"并说明缺什么。

**分工**：

| 编号 | 智能体 | 任务 |

| S1 | 方案 A-last | 结构/阈值/物理/守恒/自述一致性 |

**本地复核对所有智能体结论做了交叉检查，已更正 3 处**：① S4 的"终稿论文 result2 行数矛盾"是**比错了对象**（见 3.4 末注）；② S4 的"表面列更湿违反物理"**方向写反**（实测表面更干，方向正确）；③ S5 的"h_m 与收缩量级不自洽 800 倍"是**漏乘干基密度 ρ_d**（见第五节"量级自洽核查"）。**这三处若不更正会得出相反的结论，特此标注。**

**本地独立复算**（不依赖上述智能体结论）：判据差异（max vs 均值）、舍入分辨率、物理包络、环境尾值对场的单因素影响。

## 九、结论

1. **四套方案是同一物理模型的不同实现**；核心离散（圆柱算子、中心对称、Robin 边界、Kelvin、材料坐标、全域阈值）全部正确，质量守恒 ~10⁻¹⁴、解析解对照 4×10⁻⁵ ℃、网格/方法收敛 <1 s。
2. **答案的量级与结论对方案选择不敏感**：Q3 落在 57.17–57.47 h、Q4 落在 50.82–51.09 h，全部为"2–3 天"，差异（16–18 min）可由环境尾值口径完整解释。**同尾值下 A-last 与 B 的场值差 ≤9.6e-5 kg/kg（均值 2.5e-5）、时长差 ≤50 s**，即两套**完全不同的算法在题目要求的四位小数精度内不可区分**——这是本次独立检验最有力的结论。
3. **真正需要处理的是三件事**：①判据必须坚持"全域最大"（用体积平均会低估约 1/3，差 16–21 h）；②"四位小数 vs 严格 <0.15"的呈现冲突必须在论文中说清（半个末位 ≈171 s/97 s 过程时间，而达标裕度仅 0.2–0.7 s）；③论文中"不收缩 >120 不达标"、`BDF/120 s`、2 处表格舍入错等过时陈述必须按实际结果改写，并统一交付口径与自述。
4. **交付成熟度**：`A题_终稿/` 是唯一同时具备"全程 result2 + 显式口径声明 + 可重跑源码 + 完整验证汇总"的一套；`求解/` 缺全程 result2 且自述与交付口径不一致；**B 的源码/数组/日志全部缺失**，其算法自述只能标为"待核验主张"。
5. **推荐**：以 **A-last（`A题_终稿/`）** 作为交付底稿；A-nominal / A-mean 作为环境敏感性；B 作为独立算法复核（其工作簿已验证，可作为"A 侧结果可复现"的旁证；其追溯机制值得吸收）。
6. **论文层面建议**：两稿都缺独立"误差分析"小节——本报告第六、七章的量（判据差 16–21 h、舍入分辨 171 s/97 s、离散 <1 s、潜热 5–11%、端面 8%、尾值 16–18 min）可直接支撑增设"6.5 误差分析"，这是评审常见加分点。

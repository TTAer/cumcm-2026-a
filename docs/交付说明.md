## 计算来源与复现

`计算结果/`包含四问CSV、未舍入主场数组和summary。`验证/`保留本轮主过程、粗网格对照、Q4早期加密、坐标检查、环境情景和符号检查。原始两个数据附件随包保留。运行配置和数值库版本另见`验证/交付清单.json`。

安装`求解代码/requirements.txt`后，在本目录运行：

```text
python 求解代码/solve.py --output 复算结果
```

默认生成last主方案的四问CSV/JSON/NPZ，Q2/Q3共享过程；不会覆盖本次正式结果。`--case 2`同时生成Q2/Q3。输出包含完整Q2，可能需要数分钟。

现有`export_results.mjs`用于标准表格导出，但全程Q2规模大，此前整表导出已耗尽8GB内存。此次对已有完整Q2采用标准OOXML容器定点修订，并复用artifact生成的样式，随后全表读回核验。交付中保留导出修订脚本和说明，不能将大型表格的内存问题解释为模型失败。

## 验证边界

本轮完成数值与交付一致性修订，没有伪造内部实测数据，也没有把有效模型改写成已标定多相模型。P1中吸附平衡、潜热、真实干物质连续性及端面传递仍是物理假设限制；它们需要新的物性或观测数据，不由更小的数值残差自动解决。

当前阶段：结果与验证已交付；没有因额度而留下未导出的题目结果。报告为Markdown建模结果稿，未另行制作竞赛格式Word/PDF。
